Brief Explanation:

The system implements an enterprise-grade 3-Tier decoupled architecture designed for high scalability, academic precision, and data integrity:
1. Presentation Tier (React 18 SPA): Executes client-side thesis rendering, dynamic chapter calculation, real-time live metric pulses, Turnitin plagiarism hashing, defense slides playback, and interactive citation network visualization. It uses an event-driven bus (thesismate_docs_updated) to guarantee instantaneous state synchronization across views.
2. Application Tier (ASP.NET Core 8.0 Web API): Handles secure business logic, user identity verification via JWT, and research paper data persistence. Documented with Swagger OpenAPI, it processes paper generation requests and routes queries through Entity Framework Core 8.0.
3. Data Storage Tier (Microsoft SQL Server): Houses persistent normalized relational tables (Users and ResearchPapers) with complete ACID compliance, ensuring that all synthesized academic papers, metadata, citation lineages, and user accounts are permanently and securely stored.

6. Results and Performance Analysis

Critical Bugs / Issues
Issue Severity Resolution Final Status
Multi-Page PDF Print Spillage
Printing or saving multi-page theses caused text and figures to get clipped across page boundaries and produced unwanted blank pages.		 High Applied CSS Paged Media standards (@page { size: letter portrait; margin: 0; }), enforced physical container dimensions (8.5in x 11.0in), and capped content height per page to 800px with explicit page-break-after: always. Resolved
Home Page Document Loss & Key Mismatch
Papers generated on the Home page were not saved under authenticated user keys or were lost when an unauthenticated guest logged in.		 High Implemented thesismate_docs_guest local session tracking, created an auto-migration routine upon authentication in getUserDocs(), and added thesismate_docs_updated reactive event bus. Resolved
Backend Sync State Overwrite
When the Dashboard synced with the SQL backend, locally created offline papers were inadvertently overwritten by stale remote records.		 Medium Implemented Map-based ID deduplication (docMap.set()) to safely merge local papers and backend database records without data loss. Resolved
